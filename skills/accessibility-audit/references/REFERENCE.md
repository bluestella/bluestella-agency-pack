# Accessibility Audit Reference

## WCAG Conformance Levels
- **Level A** — Minimum accessibility (must-do)
- **Level AA** — Standard target for most products
- **Level AAA** — Enhanced accessibility (aspirational)

## Issue Severity
- **Critical** — Blocks access entirely for users with disabilities
- **Serious** — Causes significant difficulty; must fix before launch
- **Moderate** — Causes some difficulty; fix in next release
- **Minor** — Cosmetic or low-impact; fix when practical
