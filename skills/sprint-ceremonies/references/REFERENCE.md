# Sprint Ceremonies Reference

## Ceremony Cadence
| Ceremony | When | Duration |
| -------- | ---- | -------- |
| Sprint Planning | Day 1 of sprint | 1–2 hours per sprint week |
| Daily Standup | Every day | 15 minutes |
| Sprint Review | Last day of sprint | 1 hour per sprint week |
| Sprint Retrospective | After review | 1–1.5 hours |
| Backlog Refinement | Mid-sprint (weekly) | 1 hour |
