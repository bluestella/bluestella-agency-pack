# SEO Pre-Launch Checklist: [Product / Page / Release]

**Date:** [YYYY-MM-DD]
**Reviewed by:** [Name]

## Technical SEO

- [ ] Core Web Vitals all "Good" on key pages (LCP ≤ 2.5s, INP ≤ 200ms, CLS ≤ 0.1)
- [ ] Structured data (schema.org) valid for main content types
- [ ] `sitemap.xml` created and submitted to Google Search Console
- [ ] `robots.txt` configured — allows crawling of all indexable paths
- [ ] Canonical tags correct (no conflicts, no self-referencing loops)
- [ ] 404 pages return HTTP 404 status code (not 200)
- [ ] Redirects in place for moved or deleted pages (301 redirects)

## Content & Linking

- [ ] Internal linking strategy implemented on key pages
- [ ] Page titles unique and descriptive (50–60 chars)
- [ ] Meta descriptions unique per page (150–160 chars)
- [ ] H1 present and unique per page
- [ ] Images have descriptive `alt` text

## Sign-Off

- [ ] Passed Lighthouse SEO audit (score ≥ 90)
- [ ] No critical crawl errors in Google Search Console
